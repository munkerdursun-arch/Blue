# Skills à importer dans claude.ai

Pour que ces règles s'appliquent dans **toutes** vos conversations claude.ai (et pas seulement dans ce dépôt) :

1. Ouvrir claude.ai → **Paramètres** → **Capacités** (ou « Skills »).
2. Cliquer sur **Importer un skill** et choisir un fichier `.zip` de ce dossier.
3. Recommencer pour chaque fichier.

| Fichier | Rôle |
|---|---|
| `studio-premium-web.zip` | **Le plus important** : standard « studio premium » (gabarit, palettes par domaine, animations, checklist) |
| `emil-design-eng.zip` | Philosophie et règles de finition d'Emil Kowalski |
| `animate.zip`, `choreograph.zip` | Créer et enchaîner les animations |
| `animation-performance.zip` | Garder les animations fluides |
| `review-animations.zip` | Relire les animations |

Le skill taste (`design-taste-frontend`, 41 Mo) n'est pas fourni en zip : il est trop lourd et son style est en conflit avec le standard.
